# Vyapar UI Reference Pack

This package is a development/reference pack for studying the structure of Vyapar accounting software.

IMPORTANT
- PNGs in `screenshots/` are recreated reference mockups, not original Vyapar screenshots.
- They are based on publicly visible Vyapar screenshots plus Vyapar's current public feature/module documentation.
- Original/current screenshot links are listed below for direct inspection.
- The mockups are not intended as pixel-perfect copies.

## Included
1. Dashboard — KPI cards, cash, stock, bank, expenses, sales chart, low-stock area.
2. Modules & Navigation — sidebar/module grouping.
3. Sales Report — filters, summary cards, transaction table and actions.
4. Inventory — stock summary and item transaction table.
5. Settings — company, transaction, tax, print/share, backup and language areas.
6. Invoice Fields — practical field map for a professional sales invoice.

## Report groups
Transaction: Sale, Purchase, Daybook, All Transactions, Profit & Loss, Bill Wise Profit, Sale Aging, Cash Flow, Trial Balance, Balance Sheet.
Party: Party Statement, All Parties, Party-wise P&L, Sale/Purchase by Party, Sale/Purchase by Party Group.
Item/Stock: Stock Summary, Low Stock, Stock Detail, Item-wise P&L, category reports, batch/serial reports and discount reports.
Tax/GST: GST/VAT summaries and applicable GSTR/tax reports.
